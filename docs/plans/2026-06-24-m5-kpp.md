**Key structural findings (from reading the actual Fortran + the validated C port
`port2/fesom2_port/src/fesom_kpp.c`):**
- `Av` (viscAE) stays **element**-based — KPP averages node→elem internally (`oce_mixing_kpp.F90:482`,
  `minmix=3e-3` surface floor) → `impl_vert_visc_ale` is UNCHANGED.
- `Kv` (single node diffusivity) = `Kv_double(:,:,1)` (T-channel) → the vertical-diffusion TDMA is
  UNCHANGED. `Kv_double(:,:,2)` (S-channel) is computed-but-dead in CORE2 (only a gated output /
  feeds `blmc(:,:,3)`).
- NEW node arrays: `Kv_double(nl,nod,ntr)`, `ghats(nl-1,nod)`, `blmc(nl,nod,3)`, `hbl(nod)`,
  `kbl(nod)`, `dbsfc(nl,nod)`, + internal (bfsfc/caseA/stable/dkm1/ustar/Bo/dVsq). The lookup
  tables `wmt/wst(0:891,0:481)` + constants `Vtc/cg/deltaz/deltau` are module-saved (computed once).
- `dbsfc` is filled in `oce_ale_pressure_bv.F90` (:332-339): `dbsfc1(nz) = -g*(rho_surf -
  (rho(nz)+density_ref(nz,n)))/(rho(nz)+density_ref(nz,n))` — a NEW output of the (already-ported)
  pressure_bv routine. Cross-module in the oracle (`USE o_mixing_KPP_mod, only: dbsfc`); in FESOM3
  it becomes a `dyn%work%dbsfc` field written by pressure_bv, read by KPP.
- `ghats`/`blmc` are READ by the tracer solve → must persist in `dyn%work` (not KPP-locals).

### KPP module routines (FESOM2 `oce_ale_mixing_kpp.F90`)
- `oce_mixing_kpp_init` (:111) — allocate node arrays; `Vtc=concv*sqrt(0.2/concs/eps)/vonk²/Ricr`;
  `cg=cstar*vonk*(concs*vonk*eps)^(1/3)`; build `wmt/wst` lookup tables (:197-219, eqn 13/B1).
- `oce_mixing_KPP(viscAE,diffK,...)` (:306) — driver: dVsq (:344-382) → ustar/Bo (:401-411) →
  `ri_iwmix` → [`ddmix` OFF] → `bldepth` → `blmix_kpp` → `enhance` → smooth_blmc (exchange+smooth ×3)
  → combine (within BL `max(.,blmc)`, outside `ghats=0`) → exchanges → node→elem viscAE average.
- `ri_iwmix` (:1008) — interior: Ri# (store in diffK(:,:,1)) → shear-instability shape `frit` (eqn
  28b/c, Riinfty=0.8) → `viscA=visc_sh_limit*frit+A_ver`, `diffK=diff_sh_limit*frit+K_ver`
  (Kv0_const). ⚠️ several array divides (`Rib`, `1/(shear+epsln)`) — **SIMD-divide watch (L29)**.
- `bldepth` (:746) — bulk-Ri OBL depth `hbl`/`kbl`; uses sw_3d when `use_sw_pene` (:784-916);
  ekman/monob limit (:865-873). ⚠️ C port marks this HIGHEST RISK (Rib accumulation, sw interp).
- `wscale` (:946) — turbulent velocity scales via the `wmt/wst` lookup (unstable) / direct (stable).
  ⚠️ `INT()` truncation + clamp; lookup interp (the only ≤1e-10 site in the C validation).
- `blmix_kpp` (:1227) — BL mixing coeffs `blmc(3)` + `dkm1(3)` + `ghats` (eqn 10/11/20). Channel
  wiring: T uses diffK(1)→blmc(2); S uses diffK(2)→blmc(3); momentum diffK→blmc(1).
- `enhance` (:1418) — enhance blmc/ghats at the kbl-1 interface.
- `ddmix` (:1130) — double diffusion. **DEFERRED** (`double_diffusion=.false.`).
