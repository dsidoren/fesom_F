### Routines (FESOM2 file:line)

**Producers** (`oce_ale_pressure_bv.F90`):
- `sw_alpha_beta(TF1,SF1,partit,mesh)` :2751 — McDougall-1987 thermal/haline expansion. Per node/level
  scalar polynomial in `t1=T*1.00024`, `s35=S-35`, `p1=|Z_3d_n|` → `sw_beta` (:2817), `a_over_b` (:2827),
  `sw_alpha = a_over_b*sw_beta` (:2838). `exchange_nod(sw_alpha/sw_beta)`. All-scalar ⇒ no SIMD-divide trap.
- `compute_sigma_xy(TF1,SF1,partit,mesh)` :2851 — density gradient. Per node: accumulate element
  T/S gradients (`gradient_sca`) × `elem_area` over `nod_in_elem2D`, then
  `sigma_xy(1/2,nz,n) = (-sw_alpha*tx + sw_beta*sx)/vol*density_0` (:2928-2929). **`/vol` array divide → SIMD trap.**
  Exchange is a 3× `MPI_BARRIER` + per-component `exchange_nod(aux)` dance (:2935-2943).
- `compute_neutral_slope(partit,mesh)` :2949 — `ro_z_inv = 2*g/density_0/max(bvfreq(nz)+bvfreq(nz+1),eps²)`
  (:3001, **variable-divisor SIMD trap**); `neutral_slope(1/2)=sigma_xy(1/2)*ro_z_inv`, `(3)=sqrt(1²+2²)`.
  ODM95 taper `c1=0.5*(1+tanh((ODM95_Scr-ns(3))/ODM95_Sd))` (:3011-3016); optional LDD97 `c2`
  (`scaling_LDD97=.false.` ⇒ c2=1). Apply (:3049-3059): if `Fer_GM.and.Redi.and.Redi_Ktaper` →
  `slope_tapered = ns*sqrt(c1*c2)`, `fer_tapfac = c1*c2`; else `slope_tapered = ns*c1*c2`. Exchange.
- `MLD1_ind` — computed inside `pressure_bv` (:417-471): init `nzmin+1`, set to `nz` at the density-threshold
  crossing (de-Boyer-Montégut). Needed by `init_Redi_GM` `bvref` (work_core `K_GM_bvref=1`). FESOM3
  `oce_pressure_bv.F90` currently OMITS the MLD block — must add.

**`mesh_resolution`** (`oce_mesh.F90`): raw `=sqrt(areasvol(ulevels_nod2d(n),n)/pi)*2` (:2362), then ONE
node-smoothing sweep (:2370-2379, area-weighted neighbour average via `nod_in_elem2D`). FESOM3 declares +
serializes `mesh%mesh_resolution` (`mod_mesh.F90:78`) but NEVER computes it — add to `mod_mesh_areas.F90`.

**GM module** (`oce_fer_gm.F90`, new FESOM3 file `src/oce/oce_fer_gm.F90`):
- `init_Redi_GM` :215 (a.k.a. fer_compute_C_K_Redi) — builds `K=F1(x,y)·F2(z)`. F1: resolution/Rossby/ramp/
  GIN scaling → `fer_scal`, `fer_K(nzmin)=fer_scal*K_GM_max`, `fer_c=cm²`; Redi `Ki` template. F2: Ferreira
  vertical `zscaling=max(bvfreq/bvref,0.2)` (:412, **SIMD trap**) + GMzexp `exp(-|zbar|/GMzexp_zref)` +
  `K_GM_Ktaper`/`Redi_Ktaper` sqrt-split. **Replicate exactly:** ramp denom `max(rampmax-rampmin,1.e-12)`
  (:308 Intel divide-by-0 guard) and the explicit `min/max` loop replacing `minval/maxval` (:254-257).
  Companion `init_RediGM_GINsea_mask` :512 once-at-init (dead at `scaling_GINsea=.false.`, port for linkage).
- `fer_solve_Gamma` :40 — per-node TDMA (Thomas) solve `(c·Γzz − N²·Γ) = (g/ρ₀)·K·∇σ` → `fer_gamma(1:2,nz,n)`.
  Serial recurrence (forward/back sweep) ⇒ divides are NOT vectorizable (safe). `exchange_nod(fer_gamma)`.
- `fer_gamma2vel(dynamics,...)` :168 — `fer_uv(1:2,nz,el)=(1/3h)·Σ_nodes(Γnz−Γnz+1)`;
  `zinv=onethird/helem` (:202, **SIMD trap**). `exchange_elem(fer_uv)`.
- `fer_w` — in `vert_vel_ale` (`oce_ale.F90:2323-2884`): per-edge divergence of `fer_uv`, cumsum, then
  `fer_Wvel/area` (:2524, **SIMD trap**). `exchange_nod(fer_w)`.

**Redi tracer terms** (`oce_ale_tracer.F90`), `isredi=1.0` if `Redi` else `0.0`:
- `diff_part_hor_redi` :1173 (K13/K23) — adds `Tz=½(tr_z(nz)+tr_z(nz+1))`,
  `SxTz=Σ Tz·slope_tapered(1)/2`, `SyTz=Σ Tz·slope_tapered(2)/2`; fluxes become
  `Fx=Kh·(Tx+SxTz·isredi)`, `Fy=Kh·(Ty+SyTz·isredi)`. (FESOM3 has the off-path Laplacian only.)
- `diff_ver_part_redi_expl` :1086 (K31/K32) — WHOLE new routine, called `if(Redi)`. Node-averaged element
  gradients → vertical flux `vd_flux=Ki·(Sx·Tx+Sy·Ty)` interpolated to interfaces (:1158-1161).
  Divides `tr_xynodes/3/areasvol` (:1132) + `vd_flux/(z_n−z_n)` (:1161) → **SIMD traps**.
- `diff_ver_part_impl_ale` :562 (K33) — adds `Ty/Ty1 = (interface-weighted) slope_tapered(3)²·Ki·isredi`
  folded into tridiag `a=−(Kv+Ty)…`, `c=−(Kv+Ty1)…` (:761-848). FESOM3 has `Kv`-only coefficients.
- `tr_z` (`tracer_gradient_z`, oce_tracer_mod:240) `=(ttf(nz-1)−ttf(nz))/dz` — **SIMD trap**, feeds K13/K23.

**Bolus add/subtract** (`oce_ale_tracer.F90`): `UV += fer_UV` / `Wvel += fer_Wvel` before advection,
subtracted after — all `if (Fer_GM)`.
