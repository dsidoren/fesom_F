## M6 = zstar ALE

The whole core+column physics is byte-exact on the reduced `linfs` surface (M2–M5). zstar swaps the
free-surface treatment. The deltas vs linfs (oracle-verified):

1. **PGF**: linfs → `pressure_force_4_linfs`; zstar → `pressure_force_4_zxxxx` → (which_pgf=shchepetkin,
   the DEFAULT) → `pressure_force_4_zxxxx_shchepetkin`. **✅ already ported + byte-gated in M6a-1**
   (shared by zlevel/zstar; `oce_pgf.F90`).
2. **Per-step stiffness rebuild**: `update_stiff_mat_ale` (oracle `oce_ale.F90:1892-2001`) runs every
   step for non-linfs (`:3921`), updating the SSH-stiffness 2nd term by `dhe` (the element-interpolated
   `hbar(n+½)-hbar(n-½)`). linfs builds the stiffness once. NEW routine.
3. **Thickness stretches (zstar = proportional over ALL layers — SIMPLER than zlevel):**
   - `vert_vel_ale` zstar branch (oracle `:2755-2821`, ~30 lines): `dd=(hbar-hbar_old)/H`,
     `Wvel(nz)-=(zbar_3d_n(nz)-zbar_3d_n(nzmax))*dd/dt`, `hnode_new(nz)=hnode(nz)+(zbar_3d_n(nz)-
     zbar_3d_n(nz+1))*dd`, then `Wvel(1)-=water_flux` (M6a-3). All divides scalar — NO L29 trap. NO
     local-zstar fallback / min_hnode / lzstar_lev / CFL_z / cumsum (that was the zlevel complexity).
   - `update_thickness_ale` zstar branch (oracle `:1378-1436`): commit `hnode_new→hnode` + recompute
     `zbar_3d_n`/`Z_3d_n` over all layers (nzmax-1 … nzmin), then `helem`=node-mean; `exchange_elem(helem)`.
   - `init_thickness_ale` zstar (oracle `:1129-1206`): `hnode(nz)=(zbar(nz)-zbar(nz+1))*(1+hbar/H)`.
     **Cold-start simplification:** at hbar=0 this == linfs rest-state, so the existing FESOM3 init is
     correct for the cold-start gate (no init port needed for M6a-2; only for restart later).
4. **Real freshwater flux replaces virtual salt** (`which_ALE/='linfs' ⇒ use_virt_salt=.false.`,
   `oce_setup_step.F90:120`): the `water_flux` terms go live in `vert_vel_ale`/`compute_hbar_ale` and
   the `oce_fluxes` virtual-salt term turns off + ice-thermo freshwater split. Forced only (M6a-3).

DEAD under the default config (`use_cavity/use_floatice/use_partial_cell=.false.`): cavity, floatice
(use_pice), partial-cell PGF, the `oce_ale_pressure_bv.F90:369` linfs/cavity branch. Skip them.
